Implementation

Run RoleCraft on your computer

Your n8n workflow sends real application data to Ollama locally. It prepares a tailored Word document from your original template, then packages it with outreach drafts and review notes.

  1. Form submission
  2. Word template preparation
  3. Two Ollama calls
  4. Validate and export

  1. Install the prerequisites

    Install Git, Docker Desktop, and Ollama. Start Docker Desktop and Ollama.

  2. Clone and start the project

    Terminal
    git clone https://github.com/PrithviHL/rolecraft.git
cd rolecraft
ollama pull qwen2.5:3b
docker compose up -d

  3. Import the n8n workflow

    Go to localhost:5678 and set up the local owner account if prompted. Create a workflow, choose Import from File, select recruiting-workflow.json, and save.

  4. Submit and review

    Click Execute workflow to open the test form. Upload your original editable Word file (.docx), paste the job description, and add hiring-team names. The Word template keeps headings, spacing, and indentation. The form accepts DOCX only. Download the ZIP and review the Word resume and outreach drafts before sending anything. Publish the workflow in n8n to use the local production form.
